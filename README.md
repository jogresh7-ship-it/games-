# games-

A personal games collection that runs entirely from `file://` — no server needed.

## How to play

Open `index.html` in your browser. The launcher lists all your games; click any card to play.

## Games

- **Plants vs Zombies DS** — tower-defense strategy
- **Sonic** — high-speed platformer (beta)
- **Flappy Birds** — tap-to-flap arcade
- **Minecraft Pocket Edition** — block-building sandbox

## Flash games

Drop any `.swf` file into the `swf/` folder, then open it from the Flash tab in the launcher. Files are remembered between sessions.

## Folders

| Folder | Contents |
|---|---|
| `art/` | PNG box art for each game |
| `swf/` | Drop `.swf` Flash games here |
| `Plants vs Zombies DS/` | PvZ DS game files |
| `Sonic/` | Sonic platformer |
| `Flappy Birds/` | Flappy Bird clone |
| `Minecraft Pocket Edition/` | MCPE block game |
